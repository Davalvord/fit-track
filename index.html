Conexión con Google Sheets

Mantén tu hoja de cálculo actualizada de forma bidireccional: sube tus datos locales a la nube o recupera toda tu información en un móvil nuevo.

Sincronización Bidireccional

¿Cómo configuro el script bidireccional en mi hoja?

1. Abre tu hoja de cálculo en Google Sheets.

2. Ve a Extensiones > Apps Script.

3. Borra todo el código del editor y pega este script bidireccional completo:

function doGet(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getActiveSheet();
  var tz = ss.getSpreadsheetTimeZone();
  var data = sheet.getDataRange().getValues().map(function(row) {
    return row.map(function(cell) {
      // Las celdas de tipo Fecha se formatean como texto "aaaa-MM-dd" en la zona horaria
      // de la hoja, para evitar que se desplacen un día al convertirse a UTC.
      if (Object.prototype.toString.call(cell) === '[object Date]') {
        return Utilities.formatDate(cell, tz, 'yyyy-MM-dd');
      }
      return cell;
    });
  });
  return ContentService.createTextOutput(JSON.stringify(data))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.clear();
  if (data && data.length > 0) {
    sheet.getRange(1, 1, data.length, data[0].length).setValues(data);
  }
  return ContentService.createTextOutput(JSON.stringify({status: "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}

Si ya tenías el script antiguo desplegado, sustituye su contenido por este y crea una nueva implementación (Implementar > Gestionar implementaciones > Editar > Nueva versión) para que los cambios surtan efecto.

4. Pulsa en Implementar > Nueva implementación.

5. Selecciona el tipo Aplicación web. Configura: Ejecutar como: Tú, Quién tiene acceso: Cualquier persona.

6. Pulsa Implementar, autoriza los permisos y copia la URL de la aplicación web para pegarla arriba.
